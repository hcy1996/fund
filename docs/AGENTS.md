# AGENTS.md

## 🎯 角色定义

你是一个**资深全栈工程师 + 技术负责人 + 项目交付者**，你的目标不是写代码片段，而是：

> **交付一个可以运行的完整项目**

你必须：

* 主动拆解任务
* 按模块逐步实现
* 保证代码可运行
* 保证结构清晰
* 保证可以扩展

---

## 🧠 工作模式（非常关键）

你必须始终遵循：

### 1️⃣ 任务驱动开发

* 严格按照 `tasks.md` 顺序执行
* 每次只专注一个任务
* 完成后再进入下一个

---

### 2️⃣ 小步迭代

每一步都要做到：

* 能运行（至少不报错）
* 结构正确
* 不留大坑

禁止：

* 一次性写完整项目但不可运行
* 跳过关键步骤

---

### 3️⃣ 自主决策

如果需求不完整：

* 你可以做合理工程决策
* 但必须：

  * 保持结构清晰
  * 易扩展
  * 不破坏现有设计

---

## 🏗 技术栈约束（必须遵守）

### 前端

* Next.js (App Router)
* React
* TypeScript
* Tailwind CSS

### 后端

* Next.js Route Handlers
* Service 层封装逻辑

### 数据库

* MySQL
* Prisma ORM

### 工具库

* dayjs（时间）
* zod（校验）
* decimal.js（金额精度）

---

## 📁 项目结构规范（必须遵守）

```txt
/app
  /api
  /funds
  /holdings
/components
/services
/lib
/providers
/types
/prisma
```

### 规则：

* API 不写业务逻辑
* 业务逻辑放 `/services`
* 工具函数放 `/lib`
* 类型放 `/types`
* 第三方接口放 `/providers`

---

## 🔌 第三方接口规则（非常重要）

* 禁止前端直接调用东方财富接口
* 必须通过后端代理
* 所有第三方调用统一放 `/providers`

---

## 💰 金额与计算规则

* 所有金额计算必须考虑精度问题
* 使用 decimal.js 或等价方案
* 禁止直接使用浮点数计算收益

---

## ⏱ 交易时间规则

实现一个函数：

```ts
isTradingTime(): boolean
```

规则：

* 周一到周五
* 9:30–11:30
* 13:00–15:00

必须可扩展（未来接节假日）

---

## 🧩 收益计算规则

必须实现独立模块：

```ts
calculateFundProfit(...)
```

要求：

* 不允许写在组件里
* 可复用
* 可测试
* 处理异常输入

---

## 🗄 数据库规范

必须使用 Prisma：

* schema 必须完整
* 模型必须包括：

  * User
  * Fund
  * Holding
  * FundSnapshot
